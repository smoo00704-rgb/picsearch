แยกจาก PicSearch v1.7 ให้ติดตั้งเป็นแอปบนมือถือได้ทั้ง **Android และ iPhone**

ลิงก์แอป: https://smoo00704-rgb.github.io/picsearch/

## ในโฟลเดอร์นี้มีอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมดในไฟล์เดียว: UI, ตัวอ่าน .xlsx, logic ค้นหา (A → C → ลิงก์จาก B เหมือน v1.7), เก็บข้อมูลในเครื่อง, รวมรูป+รหัส |
| `sw.js` | Service worker: แคชตัวแอป ให้เปิดได้แม้ไม่มีเน็ต และอัปเดตเวอร์ชันอัตโนมัติ |
| `manifest.webmanifest` | ชื่อแอปบนหน้าโฮม ("ค้นรูปสินค้า") ไอคอน สี โหมดเต็มจอ (ทำให้ "ติดตั้ง" ได้) |
| `icons/` | ไอคอนแอป (Android, iOS, maskable) |

**ต้องอัปโหลดทุกไฟล์ทุกโฟลเดอร์ไว้ด้วยกันบนเว็บ https** แล้วให้ผู้ใช้เปิดจากลิงก์

> ⚠ **คัดลอก zip ไปแตกในโทรศัพท์แล้วเปิด index.html = ติดตั้งเป็นแอปไม่ได้**
> เบราว์เซอร์อนุญาตให้ติดตั้งแอป (manifest + service worker) เฉพาะหน้าที่เปิดจาก https
> เปิดจากไฟล์ใช้ทดสอบได้บน Android เท่านั้น (iPhone เปิดเป็นพรีวิวที่ JavaScript ไม่ทำงาน) และอาจจำข้อมูลไฟล์ลิงก์ไม่ได้

## การทำงานหลัก

- **เก็บไฟล์ลิงก์ไว้ในเครื่อง:** เลือกไฟล์ .xlsx ครั้งเดียว แอปอ่านคอลัมน์ A/B/C (ชีต `Sheet0` ถ้าไม่มีใช้ชีตแรก) แล้วบันทึกลง IndexedDB พร้อมขอ `navigator.storage.persist()` ให้ระบบไม่ลบข้อมูลอัตโนมัติ
- **ค้นได้ออฟไลน์:** การค้นทำใน `Map` ในหน่วยความจำ ไม่ต้องใช้เน็ต ต้องมีเน็ตเฉพาะตอนโหลดรูป
- **รูปมีรหัส + ชื่อสินค้าติดในตัว:** แอปวาดรูป + แถบด้านล่าง (บรรทัดแรก รหัส เช่น `123456 (8955965)` / ถัดไป ชื่อสินค้า สูงสุด 3 บรรทัด) ลง `<canvas>` แล้วแสดงเป็น PNG กดค้างคัดลอก/บันทึก/แชร์ได้ไปด้วย
  - **ชื่อสินค้า:** ใช้คอลัมน์ **E** (`s_Note50`) เป็นหลัก ถ้า E ว่างใช้คอลัมน์ **D** (`ShortDescription`) ; ตัดบรรทัดภาษาไทยด้วย `Intl.Segmenter("th")` ไม่ให้เครื่องหมายปิด (`.` `)` ฯลฯ) ขึ้นบรรทัดใหม่
  - ข้อมูลที่บันทึกในเครื่องจาก v2.5 หรือเก่ากว่ายังไม่มีชื่อสินค้า → แอปจะเตือนให้กด "อัปเดตไฟล์ลิงก์" แล้วเลือกไฟล์อีกครั้ง 1 ครั้ง
  - ปุ่ม **↗ เปิดรูป** — เปิดหน้าดูรูปของแอปในแท็บใหม่ (`index.html#view=...`) รูปมีรหัสในตัวเช่นกัน
  - ⚠ ใส่รหัสลงในไฟล์รูปได้เฉพาะเมื่อเว็บที่เก็บรูปส่ง header CORS (`Access-Control-Allow-Origin`) ถ้าไม่ส่ง แอปจะขึ้น ⚠ และใช้วิธีสำรอง: แสดงรหัสใต้รูป + หน้า "เปิดรูป" สำหรับแคปหน้าจอ
- **อัปเดตไฟล์ลิงก์:** เมนู "📄 ไฟล์ลิงก์" → "🔄 อัปเดตไฟล์ลิงก์" → เลือกไฟล์ใหม่ ข้อมูลเดิมจะถูกแทนที่ทั้งชุด (ถ้าอ่านไฟล์ใหม่ไม่สำเร็จ ข้อมูลเดิมยังอยู่)
- **ไม่พึ่ง CDN:** อ่าน .xlsx ด้วย `DecompressionStream("deflate-raw")` ของเบราว์เซอร์แทน fflate
- **ต้องการ:** iOS 16.4 ขึ้นไป / Android Chrome 103 ขึ้นไป

## ขั้นตอนนำขึ้นเว็บ (เลือกหนึ่งทาง)

### ทาง A: ขอ IT (แนะนำสำหรับใช้ในบริษัท)
ส่งโฟลเดอร์นี้ให้ IT วางบนเว็บเซิร์ฟเวอร์ภายในหรือ Azure Static Web Apps ที่มี https
เป็นไฟล์ static ล้วน ไม่ต้องมีฐานข้อมูลหรือโค้ดฝั่งเซิร์ฟเวอร์

### ทาง B: GitHub Pages (ฟรี ทำเองได้) — ที่ใช้อยู่ตอนนี้
1. สมัคร/ล็อกอิน https://github.com
2. กด **New repository** ตั้งชื่อ เช่น `picsearch` เลือก **Public** แล้วกด Create
3. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมด**ข้างใน**โฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`) ลงไป กด **Commit changes**
4. ไปที่ **Settings → Pages** ตั้ง Source = **Deploy from a branch**, Branch = `main` / `(root)` กด Save
5. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://<ชื่อผู้ใช้>.github.io/picsearch/`

> โค้ดแอปเปิดดูได้แบบสาธารณะ (มีชื่อ/อีเมลผู้พัฒนา) แต่**ไม่มีข้อมูลสินค้าหรือลิงก์รูปอยู่ในโค้ด** ข้อมูลอยู่ในไฟล์ลิงก์ที่ผู้ใช้เลือกในเครื่องตัวเองเท่านั้น ไม่ถูกส่งขึ้นเว็บ — ควรแจ้ง IT ก่อนใช้จริง

## วิธีติดตั้งบนมือถือ (ส่งให้ผู้ใช้)

ส่งลิงก์ทาง LINE แนะนำให้เติม `?openExternalBrowser=1` ท้ายลิงก์ เพื่อให้เปิดใน Safari/Chrome แทนเบราว์เซอร์ของ LINE:
`https://smoo00704-rgb.github.io/picsearch/?openExternalBrowser=1`

**Android (Chrome)**
1. เปิดลิงก์แอป → แตะปุ่ม **⬇ ติดตั้งแอป** มุมขวาบน (หรือเมนู ⋮ → "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก")
2. เปิดแอปจากไอคอน "ค้นรูปสินค้า" → แตะ **เลือกไฟล์ลิงก์** → เลือกไฟล์จาก OneDrive หรือไฟล์ที่ดาวน์โหลดไว้

**iPhone / iPad (ต้องใช้ Safari — iPhone ไม่มีปุ่มติดตั้งเด้งขึ้นมาเอง)**
1. เปิดลิงก์แอปใน **Safari** → แตะไอคอน **แชร์** (สี่เหลี่ยมมีลูกศรขึ้น มุมขวาของช่องที่อยู่เว็บ) → เลื่อนลง → **เพิ่มไปยังหน้าจอโฮม** → เพิ่ม
2. เปิดแอปจากไอคอน "ค้นรูปสินค้า" บนหน้าโฮม (**ต้องเลือกไฟล์ในแอปที่ติดตั้งแล้ว** เพราะข้อมูลของแอปบนหน้าโฮมแยกจาก Safari)
3. แตะ **เลือกไฟล์ลิงก์** → เลือกจาก OneDrive ในหน้า "เลือกหา" (Browse) หรือจาก "ในไอโฟนของฉัน"

## ถ้าใช้งานไม่ได้
ด้านล่างสุดของแอปมี **🛠 ข้อมูลสำหรับแจ้งปัญหา** แสดงเวอร์ชันเบราว์เซอร์ ความสามารถที่รองรับ และ log ทุกขั้นตอน
(แตะปุ่มเลือกไฟล์, ได้ไฟล์อะไร ขนาดเท่าไร, อ่านล้มที่ขั้นไหน, บันทึกลงเครื่องได้ไหม, รวมรูป+รหัสได้ไหม) กด "คัดลอก" แล้วส่งมาได้เลย

## เมื่อแก้ไขแอปเวอร์ชันใหม่
1. แก้ไฟล์แล้วเปลี่ยน `CACHE` ใน `sw.js` (เช่น `picsearch-app-v2.7`) และ `APP_VERSION` + ป้ายเวอร์ชันใน `index.html`
2. GitHub: **Add file → Upload files** → ลากไฟล์ทับ (ชื่อต้องตรงเป๊ะ ระวัง `index (1).html`) → **Commit changes**
3. ใช้ลิงก์เดิม ไม่ต้องส่งลิงก์ใหม่ — มือถือที่ติดตั้งแล้วได้เวอร์ชันใหม่เมื่อเปิดแอปตอนมีเน็ต (มีข้อความให้ปิด-เปิดแอปใหม่) ข้อมูลไฟล์ลิงก์ในเครื่องไม่หาย
4. ถ้าเปลี่ยน**ชื่อแอป/ไอคอน**: iPhone ต้องลบไอคอนแล้วเพิ่มลงหน้าโฮมใหม่ / Android อัปเดตเองภายใน ~1 วัน
